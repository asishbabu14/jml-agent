# Request access

1. Name the catalog group, such as app-wiki or app-slack, and say why you need it.
2. The assistant files the request. It does not add you to the group.
3. IT approves ordinary groups. Groups whose names start with phi- also need your manager and a security partner.
4. You get a note when the change is done. Until then, assume you do not have access.
