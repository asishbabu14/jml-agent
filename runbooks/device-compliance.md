# Device compliance

1. Ask the assistant to check the device for your email.
2. The answer comes from the labelled mock inventory, not from a live MDM tenant.
3. A compliant Mac in this lab shows FileVault on and an endpoint agent reported as protected.
4. If the laptop will not turn on, that is a ticket for the endpoint queue, not a directory change.
